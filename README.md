# Трекер привычек — Spec Driven Development

Статус: **v0.1.0 готова**, пять этапов завершены 08.11.2026. Спецификация и макеты утверждены до кода. Пользователь подтвердил сохранение после перезапуска, переименование/удаление и статистику; автоматические проверки прошли. Пределы приёмки указаны ниже.

**Оба согласования получены:** поведение из SPEC.md и [макеты v0.1](docs/mockups/README.md) — главное окно, статистика, диалоги и состояния.

## Цель

Создать первую версию десктопного трекера привычек для Windows 10 и сравнить процесс Spec Driven Development с другим подходом к вайб-кодингу. Сначала согласуется поведение, затем последовательно реализуются и проверяются этапы.

## Требования и границы

Один пользователь, без авторизации. Создание, переименование и удаление привычек; недельная таблица с понедельника по воскресенье; переключение недель; установка и снятие отметок без дубликатов; текущие серии; статистика за 7 и 30 дней; встроенные мотивирующие цитаты; сохранение в PostgreSQL. Интерфейс на русском, пастельные розовые и бежевые цвета. Напоминания, цели, категории, расписания, экспорт и синхронизация не входят в версию.

Подробные правила, экраны, модель данных, вопросы и приёмка: [SPEC.md](SPEC.md). Обследование окружения: [docs/ENVIRONMENT.md](docs/ENVIRONMENT.md). Учёт времени, ошибок и ручных действий: [docs/WORK_LOG.md](docs/WORK_LOG.md).

## Стек

C++17, Qt 6.9.1 Widgets и SQL, PostgreSQL через QPSQL; CMake 3.30.5, Ninja 1.12.1, MinGW 13.1.0 из комплекта Qt. Qt Test для проверок. Графики будут рисоваться средствами Qt Widgets/QPainter, без дополнительной библиотеки диаграмм. Сборка, QPSQL, схема и оба состояния окна проверены на Windows 10 build 19045 с PostgreSQL 18.6 на основном localhost:5432.

## План: пять проверяемых этапов

| Этап | Результат | Проверка завершения |
| --- | --- | --- |
| 1. Каркас и отдельная БД | Сборка окна, внешняя конфигурация, схема БД, диагностика подключения | Сборка и запуск; QPSQL загружается; соединение именно с habit_tracker_sdd; таблицы созданы; повторная инициализация безопасна; ошибка соединения понятна и не раскрывает секреты |
| 2. Привычки | Создание, переименование и удаление через интерфейс и PostgreSQL | Пустые названия отклоняются, отмена безопасна, изменения сохраняются после перезапуска, удаление каскадное |
| 3. Неделя и серии | Недельная таблица, навигация, отметки, текущие серии | Проверки понедельника, границ года, високосной даты, повторной записи и серий; ручная проверка переходов и сохранения |
| 4. Статистика и оформление | Графики 7/30 дней, итоги, цитата, пастельный интерфейс | Сверка с известными отметками, пустые периоды, длинные названия; осмотр окна на целевой системе |

Перед каждым этапом агент сообщает краткий план; после — фактические изменения, запущенные проверки, ошибки и необходимые действия пользователя. Следующий этап начинается только отдельным шагом после отчёта о предыдущем. Не выполненные проверки отмечаются явно. Изменения согласованных правил сначала обсуждаются.

## Настройка и безопасность

Для этой версии выделяется база `habit_tracker_sdd`, для интеграционных проверок — `habit_tracker_sdd_test`; другая версия приложения использует другое имя базы на том же сервере. Пароль не хранится в репозитории, документах, журнале или примерах команд. Подключение без авторизации приложения не означает отсутствие учётной записи PostgreSQL.

## Сборка и запуск

Команды из корня проекта в Windows PowerShell:

```powershell
.\scripts\build.ps1 -Test
.\scripts\run.ps1
```

Базы на текущем компьютере уже настроены. run.ps1 запрашивает пароль роли приложения локально, без сохранения в файлы. Только при первоначальной настройке нового сервера нужен scripts/setup-database.ps1 с действующим административным входом. Подробности: [инструкция запуска](docs/RUN.md) и [настройка этапа 1](docs/STAGE1.md).

Собранный файл: `build\qt\habit_tracker.exe`. Сборка временно использует свободную букву H: для обхода ошибки Qt moc на пути с кириллицей. Если H: занят, укажите `-BuildDrive J:` с другой свободной буквой; ограничения кэша описаны в инструкции. Системный PATH не меняется.

Доступны создание, переименование и удаление привычек, переключение недель, отметки по датам, текущие серии, встроенная цитата и статистика за 7/30 дней. Сегодня выделено розовым, выполненные дни — зелёным. Основной сервер настроен: habit_tracker_sdd и habit_tracker_sdd_test принадлежат роли habit_tracker_sdd_app без административных прав. Итоговые 10/10 наборов CTest проходят без ошибок и пропусков; проверены отдельные процессы и масштабы Qt 125/150%. Полный перечень доказательств и не выполненных испытаний — в docs/ACCEPTANCE.md. Автономный установщик не создавался: для запуска нужны обнаруженные Qt/libpq, scripts/run.ps1 задаёт пути к ним.
