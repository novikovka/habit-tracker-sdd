## Итоговая автоматическая проверка

Команда: `scripts/build.ps1 -Integration`. Windows 10 build 19045, Qt 6.9.1, MinGW 13.1.0, PostgreSQL 18.6; только habit_tracker_sdd_test.

| Набор | PASS |
| --- | ---: |
| DatabaseSmokeTest | 7 |
| WindowSmokeTest | 4 |
| HabitRepositoryTest | 13 |
| HabitUiTest | 4 |
| CalendarTest | 14 |
| CompletionRepositoryTest | 4 |
| WeekUiTest | 3 |
| StatisticsTest | 5 |
| StatisticsUiTest | 4 |
| PersistenceProcessTest | 3 |
| Итого | 61 |

CTest: **10/10**, ноль FAIL/SKIP. 61 PASS включает 20 служебных init/cleanup; это не 61 независимый пользовательский сценарий. Последний полный запуск занял 11,62 с по CTest.

Текстовые результаты последнего запуска и отдельных DPI-прогонов сохранены в [TEST_RESULTS.txt](TEST_RESULTS.txt).

Дополнительно HabitUiTest, WeekUiTest и StatisticsUiTest запущены отдельно с QT_SCALE_FACTOR=1.25 и 1.5: шесть успешных запусков. Масштаб задан только окружением дочернего процесса, не настройками Windows. Снимки статистики при [125%](screenshots/final-dpi125-statistics.png) и [150%](screenshots/final-dpi150-statistics.png) визуально осмотрены.

После проверок SQL подтвердил ноль оставшихся привычек и отметок в тестовой базе. Рабочая база не изменялась тестами. Пароли не включены в файлы, снимки и Git.

## Границы результата

Готова первая версия для обследованного окружения. Не выполнялись испытания на другом компьютере, реальный сетевой обрыв во время записи, смена системных часов/часового пояса, полный ручной Tab-проход и длительное нагрузочное тестирование. Календарные условия моделировались без изменения Windows. Отдельный автономный установщик не создавался: сборка использует установленные Qt и PostgreSQL, запуск — через scripts/run.ps1.
